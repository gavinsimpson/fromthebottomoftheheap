# Migration records

- `post-manifest.csv` snapshots each historical post's source, canonical QMD,
  URL, title, subtitle, original timestamp, excerpt, image, publication state,
  category, tags, paired-Rmd status, and hidden block-chunk count.
- `rmd-md5.tsv` records byte-level checksums for the 37 original post Rmd files.
- `route-manifest.txt` is the complete baseline of 386 committed index routes
  from the final Jekyll output.

These files are regenerated by `scripts/migrate-content.R` and consumed by the
validation suite. They are safe to commit and contain no Disqus private data.
